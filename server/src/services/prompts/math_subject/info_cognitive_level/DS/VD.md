# Mức độ VD (Vận dụng)

- Mô tả chi tiết: Thí sinh phải áp dụng kiến thức vào tình huống cụ thể, phân tích bài toán thực tế, tính toán kết hợp nhiều bước, hoặc chứng minh một kết quả phức tạp hơn.

- Đặc điểm: Phát biểu thường liên quan đến bài toán ứng dụng (chi phí, xác suất, hình học không gian). Thí sinh cần tính toán, phân tích điều kiện, hoặc loại trừ trường hợp để kết luận Đúng/Sai.
