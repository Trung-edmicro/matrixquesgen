# Mức độ VD (Vận dụng)

- Mô tả: Thí sinh phải kết hợp nhiều kiến thức, giải quyết tình huống thực tế, lập mô hình, tính toán phức tạp, sử dụng công thức trong ngữ cảnh mới hoặc có nhiều ràng buộc. Bao gồm cả các bài đòi hỏi phân tích sâu, tối ưu hóa, phân trường hợp.

- Đặc điểm chính:
  - Lập phương trình/hệ phương trình từ bài toán thực tế.
  - Tính giới hạn, tích phân xác định, thể tích, trung bình.
  - Sử dụng tính chất hình học kết hợp tọa độ, tổ hợp có điều kiện.
  - Phân tích nhiều trường hợp, đếm tổ hợp với ràng buộc phức tạp.
